# Правила проекта

Все задачи приложения направлены на максимально возможную автоматизацию рутинных процессов. Настройка роутера запускается одной кнопкой, автоматически проходит распознанные шаги, сохраняет сеть в Android с необходимым системным подтверждением и выполняет дополнительную настройку после переподключения. Использовать сценарий Tenda как образец. Подсказки допустимы при ошибках и обязательных действиях Android.

Готовые обновления доводить до подписанного APK и публикации в GitHub Releases без дополнительного запроса пользователя.
