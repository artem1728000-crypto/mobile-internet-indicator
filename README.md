# Мобильный интернет

Индикатор для Android 8.0 и новее. Установите APK из Releases, откройте приложение и разрешите уведомления. Наблюдение запустится сразу. После перезагрузки Android возобновит его после разблокировки телефона, если наблюдение было включено.

| Значок | Значение |
| --- | --- |
| Галочка | Доступен внешний контрольный адрес |
| Восклицательный знак | Вероятно, белый список. Яндекс доступен, внешний адрес не отвечает |
| Крест | Мобильной сети нет или обе проверки не прошли |
| Три точки | Идёт первая проверка |

Проверки выполняются через мобильную сеть, включая случаи, когда телефон подключён к Wi-Fi. Внешний контрольный адрес — TCP 8.8.8.8:53, для Яндекса используется HTTPS ya.ru. Это признаки доступности двух адресов, поэтому блокировка самого контрольного адреса может выглядеть как белый список. Интервал — 30 секунд после окончания проверки. Для ухудшения результата на той же сети нужны два одинаковых результата подряд. Потеря мобильной сети отображается сразу. Android может отложить опрос в режиме сна. Если значок скрыт, проверьте настройки уведомлений и отображения тихих значков в строке состояния.

Для отладки нужен JDK 17, Gradle 8.11.1 и Android SDK 35. Команда сборки — `gradle lintDebug assembleDebug`. GitHub Actions проверяет код при отправке в main. Тег `v*` дополнительно собирает и проверяет подписанный APK, используя секреты `ANDROID_SIGNING_KEY` (PKCS12 в Base64) и `ANDROID_SIGNING_PASSWORD`. APK из артефакта можно прикрепить к закрытому релизу.
`nРежим раздачи. Точка доступа другого телефона определяется как Wi-Fi. Значок показывает мобильную сеть телефона с установленным приложением, даже если трафик навигатора идёт через раздачу.
