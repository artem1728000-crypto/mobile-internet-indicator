# Мастер роутеров

Индикатор для Android 8.0 и новее. Установите APK из Releases, откройте приложение и разрешите уведомления. После перезагрузки Android возобновит включённое наблюдение после разблокировки телефона.

| Значок | Значение |
| --- | --- |
| Галочка | Сойка отвечает по HTTPS |
| Восклицательный знак | Вероятно, белый список. Яндекс отвечает, Сойка недоступна |
| Крест | Нет подключения или обе проверки не прошли |
| Три точки | Идёт первая проверка |

В режиме «Активное подключение» используется сеть, которую Android выбрал для приложений. Выберите его для Wi-Fi, включая раздачу с другого телефона. Режим «Только мобильная сеть» проверяет SIM этого телефона даже при подключённом Wi-Fi. Выбор запоминается.

С версии 2.14.5 приложение проверяет HTTPS-ответ от `sojka.mobiforce.ru` и использует `ya.ru` как контрольный адрес. Оба запроса идут через выбранную в приложении сеть Android. Для Сойки измеряется время до заголовков ответа без перехода по редиректам. Любой итоговый HTTP-код от 200 до 599 подтверждает доступ к серверу. Код виден рядом с задержкой и помогает заметить ошибку сервиса. Если отвечает только Яндекс, возможны белый список или сбой связи с Сойкой. В истории предыдущих версий «Доступ есть» относится к прежней проверке Google DNS.

Автоматическая проверка запускается через 30 секунд после завершения предыдущей. Кнопка «Проверить сейчас» запускает внеплановую проверку. Ухудшение на той же сети подтверждается повторным замером.

Для сборки нужен JDK 17, Gradle 8.11.1 и Android SDK 35. Команда — `gradle lintDebug assembleDebug`. Тег `v*` дополнительно запускает сборку и проверку подписанного APK. GitHub Actions использует секреты `ANDROID_SIGNING_KEY` (PKCS12 в Base64) и `ANDROID_SIGNING_PASSWORD`.

«История по дням» показывает отрезки наблюдения, тип подключения и итоговое время по состояниям. Дату можно выбрать в календаре. Фильтр 08:00–17:00 сужает выбранный день до рабочего времени. История сохраняется локально начиная с первого запуска наблюдения в версии 1.2.0. Длинная пауза между замерами отображается как отсутствие наблюдения.

«Проверить обновления» обращается к публичному GitHub Releases. Приложение также проверяет свежую версию при открытии, если со времени последней успешной проверки прошли сутки. Кнопка загрузки открывает подписанный APK в браузере. Установку поверх текущей версии подтверждает пользователь в Android.

### Проверка мастера Tenda

- TX2L Pro — первичная настройка и объединение диапазонов проверены пользователем.
- RX2 Pro — первичная настройка с предложением сохранить защищённую сеть и объединение диапазонов подтверждены 15.11.2026 на версии 2.8.2.
- AX12 Pro — полный сценарий подтверждён 15.11.2026 на версии 2.10.2: первичная настройка защищённой двухдиапазонной сети, вход, переход через веб-версию и автоматическое отключение автосогласования WAN/LAN. Порт 1 сохраняет роль WAN.

### Мастер Xiaomi

В версии 2.12.1 добавлен сценарий для AX3000T с китайским интерфейсом MiWiFi 1.0.90. Нажимайте «Xiaomi — настроить» на каждом новом экране. Сценарий помогает пройти настройку DHCP без WAN-кабеля, заполнить пароль Wi-Fi и пароль входа, перейти к настройкам WAN и выбрать фиксированный порт 1. Применение настроек подтверждается в интерфейсе роутера.

Сценарий составлен по снимкам AX3000T. Проверка на устройстве и подтверждение совместимости с AX1500, BE3600 и BE5000 ещё предстоят.
